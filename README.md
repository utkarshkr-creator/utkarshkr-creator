## What I Build

Most of my work lives at the intersection of performance and reliability — systems where getting the architecture wrong shows up in your latency numbers, not just in a code review.

**Current project I'm most proud of:**

[Real-Time Cryptocurrency Trading Platform](https://github.com/utkarshkr-creator/REAL-TIME-TRADING-ENGINE) — built from scratch in Go.
In-memory order book · 1.8M+ ops/sec (benchmarked) · Redis Streams for event sourcing · Zero data loss crash recovery · WebSocket fan-out to thousands of clients · 6 microservices on Docker.

The hardest part wasn't the throughput. It was getting crash recovery right — three attempts before the event replay ordering worked correctly under all failure conditions.
